# Shop Inventory (ip1-e20230987)

Staff record stock in and out. Managers see low-stock alerts and a stock movement report.

Stack: Vue 3 + TypeScript, NestJS, PostgreSQL with Prisma (backend and database come in later checks).

## Run the frontend (Check 1)
```
cd frontend
npm install
npm run dev
```
Open the address shown in the terminal (usually http://localhost:5173).

## Features (planned)
- Login with 2 roles: Staff and Manager
- Product list with search and pagination
- Stock in and stock out (Staff)
- Add / edit / delete products (Manager)
- Low-stock alerts (Manager)
- Stock movement report (Manager)
